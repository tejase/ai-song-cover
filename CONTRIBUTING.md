# Contributing

Use Node.js 22.12+ and `npm ci`. Read AGENTS.md and docs/AGENT_WORKFLOW.md.
Keep changes focused and add tests for parsing, timing, validation, or renderer logic.
Run `npm test`, `npm run build`, and `npm run check:public` before a PR.

For visual changes, provide a proof made with original or appropriately licensed
media and state which scenes/durations you checked. Never attach someone else's
private recording. Do not commit user audio, personal lyrics/timings, exports,
models, secrets, or machine paths. Review asset/dependency provenance/licenses.
Original contributions are under LICENSE. CI checks logic/build/file hygiene,
not perceptual video quality or vocal alignment; manually review those too.
